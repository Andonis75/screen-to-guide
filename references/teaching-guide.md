# 教学视频转阅读文档

用于以讲解、原理、演示、代码或幻灯片混合构成的视频。目标是读者能完整理解并复现视频实际讲授的内容，不是逐字转写，也不是几条摘要。使用自己的文字组织教材，保留必要的名称、参数和命令。

## 取得和处理材料

1. 取得本地完整视频。公开链接可用 `scripts/acquire_video.py "链接" --output-dir "素材目录"` 下载单条视频与可用字幕；首次需要显式准备可选下载依赖，见 [usage.md](usage.md)。核对 `acquisition-status.json` 中的来源、时长和实际清晰度，再使用它返回的本地视频路径。按用户给出的优先级选择备用链接；下载失败记录具体原因。媒体与大缓存放用户允许的空间，不另行下载模型。
2. 首次使用先按 `usage.md` 准备运行环境。教学材料入口优先查找与视频同名的字幕；没有通过筛选的字幕时使用本地 ASR，此时需要显式执行 `scripts/run.ps1 --prepare-model --kind asr` 准备语音模型。教学模式不要求视觉大模型。使用 Skill Python 运行：

   ```powershell
   .runtime/venv/Scripts/python.exe -X utf8 scripts/prepare_lesson.py "视频路径" --output-dir "新输出目录"
   ```

   输出 `lesson-evidence.json`、字幕或完整音轨转写、带真实时间的原图、OCR 和联系表。`--subtitle-file "字幕路径"` 可指定 SRT、VTT 或支持的 JSON；`--no-subtitles` 强制走本地 ASR。只有嵌在画面里的字幕不是可直接读取的字幕文件。时间覆盖筛选只用于选择材料，不证明内容完整或识别准确；未通过筛选时回退本地转写。当前本地媒体边界为单段最多 30 分钟、2 GiB；超过边界时明确分段、保留原片时间偏移后处理所有分段，不能静默截掉后半段。

   同一材料任务中断后，在相同命令上加 `--resume`。入口核对源文件、字幕来源、参数及产物哈希，复用已完成的转写、音轨、原帧、OCR 和播放副本，再继续缺失阶段。来源或参数变化时用新输出目录。修改中间稿不需要重新准备材料；不把材料恢复说成智能体写作会自动断点续写。
3. 先读完转写与覆盖记录，再按时间通看全部联系表。原理图、命令、表单、参数和结果截图按需查看原图或补采关键片段。OCR 和转写只是候选文字，名称与数值以可见画面和上下文相互校正。
4. 为每个教学主题建立起止时间，记录视频开头、结尾、广告或重复片段的处理。检查每段有实质教学内容的时间都进入章节，避免只整理开头或某次演示。音频有大段缺失时先重取/补转写该段，再声称覆盖完成。

## 写成什么

- 开头说明学完能做什么、适合谁、所需账号/文件/软件。准备项来自视频实际要求。
- 通常在 `quick_overview` 写 3–6 条简洁重点，让读者先了解原理、主要流程和最终结果，再进入完整章节。字段可省略，最多 8 条、每条 300 字以内；概览不替代实操步骤。
- 按学习顺序组织章节：概念和原理、工具各自作用、实际操作、验证结果、常见问题。没有的部分不硬凑。
- 原理用连贯短段落解释因果关系；操作用有顺序的步骤，写清入口、输入、关键选项和完成标志。
- 代码单独保留可复制代码块；看不清的命令不猜。视频有展示才写成已演示步骤，仅口头提及的功能写成讲解。
- 对影响跟做的包名、启动命令、参数层级与路径逐项查看原帧。图注只描述对应截图实际显示的界面或结果；发现错位时重新选图或修改中间稿，不直接修改最终文件。
- 每章保留原视频时间入口，选能帮助理解的原始截图。截图数量按信息需要决定，不为凑页数重复同一画面。
- 教师的经验判断、收益/准确率/防封等承诺保持归属，不升级成已验证事实。原视频与当前官方资料矛盾时，简明说明具体差别并链接官方来源；外部补充与视频所教内容区分。
- 视频本身省略的必要步骤就明确指出这一处，不伪造实操过程；正文不反复出现“需核对”、内部识别日志或给读者分派制作工作。

## 固定渲染

由调用 Skill 的 Agent 编写中间 `analysis/lesson-manifest.json`，然后运行：

```powershell
.runtime/venv/Scripts/python.exe -X utf8 scripts/render_lesson.py --manifest "教程JSON" --output-dir "本次输出目录"
```

已有输出要重建时显式加 `--overwrite-guide`。脚本一次生成 `guide.html`、`guide.md`、`lesson.json`，不要再手改生成文件。

Manifest 基本结构（全部正文为纯文本，代码仅用于展示）：

```json
{
  "schema_version": 1,
  "kind": "lesson",
  "title": "教学主题",
  "summary": "阅读后能理解和完成的事情。",
  "quick_overview": ["先理解这项功能解决什么问题。", "准备所需环境，再按章节操作并检查结果。"],
  "source": {"name": "原视频标题", "url": "https://example.com/video", "author": "作者", "duration_seconds": 300, "sha256": "来源文件哈希", "width": 1280, "height": 720},
  "video": "playback.mp4",
  "prerequisites": ["视频中实际使用的准备项"],
  "sections": [{
    "id": "chapter-1", "title": "第一章主题", "start_seconds": 0, "end_seconds": 60,
    "paragraphs": ["原理与目的的解释。"], "bullets": ["需要记住的要点"],
    "steps": ["有实操时写具体步骤。"],
    "code_blocks": [{"language": "powershell", "code": "视频展示的命令"}],
    "images": [{"path": "frames/frame-0001.jpg", "timestamp_seconds": 20, "caption": "这幅图帮助理解的内容"}],
    "note": "只在有具体必要时补充。"
  }],
  "glossary": [{"term": "术语", "definition": "本教程中的含义"}],
  "references": [{"title": "原视频", "url": "https://example.com/video"}],
  "coverage": {"method": "完整转写与分段画面阅读", "intervals": []}
}
```

`coverage` 中记录实际覆盖范围及省略原因，保留制作依据但不混入读者正文。图片路径与时间来自本次材料；不要捏造截图时间。

## 结束检查

一轮检查重点放在漏掉教学主题、写错命令/参数、错误操作顺序、图文错位和过度承诺。字幕命中或缓存复用不跳过这轮内容检查。修正中间稿后再生成；文字和格式小差异不应触发整片模型重跑。打开 HTML，检查概览、正文、关键图片与视频跳转；至少验证一次章节结束自动暂停和重播。截图时间入口从该截图位置开始，到本章结束时暂停；“重播本章”回到章节起点，“继续播放完整视频”解除范围限制。章节是同一完整视频中的时间范围，不宣称另外导出了独立切片。确认 Markdown 内容同样完整。说明本次验证的视频范围，不把一个样例通过当成所有课程都已准确可用。

修改播放器时运行 `node --test tests/test_lesson_playback.cjs`，并在支持视频 Range 请求的本机预览页验证真实视频到点暂停。浏览器播放限制不是重新编码的逐帧裁剪。
